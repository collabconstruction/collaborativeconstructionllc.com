## Evidence rules

`verified-source` means observed in a cited file or source, not necessarily independently verified in the real world. `owner-confirmation-needed` marks company claims requiring records or owner sign-off. `hypothesis` marks proposed explanations and tests. `unknown` is never zero. Dates refer to observation unless explicitly described as an event date. Recheck regulatory, API and competitor facts before acting.

This folder is outside Eleventy's `src/` input and is not copied to the public site by the current build. It may still be shared through Git: store customer identities, financial exports and credentials outside the repository. Only approved aggregate summaries belong here. New research belongs in Markdown with direct sources, dates and a named next decision.

## What was accomplished in this run

Company/source review, public website GET snapshots, competitor and local research, repository due diligence, five company-specific skills, reusable templates, an implementation backlog, and a data connection plan. No account connection, outbound customer message, profile edit, ad spend, recurring monitor or deployment was performed. Claude was invoked but its weekly account limit prevented the independent review.
