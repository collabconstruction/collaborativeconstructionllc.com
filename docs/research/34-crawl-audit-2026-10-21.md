# Crawl audit, October 21, 2026 (raw HTML view)

Run by Claude with `python3 scripts/seo_audit.py` plus `curl` on the live site. This is what a crawler sees before JavaScript. It is not Google's rendered view or its index.

## Verified on the live site
- All 9 pages return 200 and each has exactly one H1 in the server HTML. No H1 is added by JavaScript.
- Every page has a unique title, a meta description, an absolute canonical equal to its URL, og:title, og:description, og:image and og:url, and JSON-LD that parses. No noindex meta, no `X-Robots-Tag` header. Every image has alt text.
- `sitemap.xml` lists the 9 canonical URLs. `/about` answers one 301 to `/about/`.
- `www` returns HTTP 522.
- `robots.txt` contains Cloudflare's managed block about 9 times, then the repo's own rules.

## Found and fixed on branch `claude/seo-crawl-fixes`
- About H1 was `building.<br>Clear`, read as "building.Clear" by tools that strip tags. Now has a space.
- Gallery description still mentioned removed wording. Rewritten.
- robots.txt grew on every deploy. Cause: the overlay deploy copied the live robots.txt, which already holds Cloudflare's block, and Cloudflare added it again. The overlay now ships the repo's file and stops with NOT READY if the block is in it. The release check fails if the built robots.txt has the block, has more than one Sitemap line, or loses `Disallow: /api/`. The overlay was run end to end on Oct 21 and produced a clean robots.txt.
- New release checks: one meaningful H1 per page, H1 words do not run together when tags are stripped, og tags present, og:url equals canonical.

## Not fixed, needs the owner
- `www` 522: Cloudflare DNS record and redirect rule.
- Titles and H1s on 7 pages carry no place (for example "Home Additions"). Adding places needs the confirmed service towns. Proposed: "Home Additions on Cape Cod", "ADU Builder on Cape Cod", "Home Renovation on Cape Cod", "Custom Home Builder on Cape Cod".
- Every page uses the same og:image. Lower priority.
- Sitechecker's H1 warning: the raw HTML has an H1 on every page, so the cause is unknown. Send the exact URL and message.
- Cloudflare AI Crawl Control and bot settings: check that search and answer bots can reach the site and Googlebot is never blocked.
