## Access, copyright and privacy rules

- Facebook's Groups API has been discontinued. LinkedIn prohibits unauthorized website scraping and automation. A search-indexed group description does **not** provide authorized access to its current posts.
- Do not create browser bots, replay sessions, bypass logins, or automate joining/posting. Use public web indexing and independently permitted sources for scheduled research.
- The GitHub repository is **public**. Do not commit private group discussion text, individuals' names or profiles, contact details, account credentials, private notifications, copied copyrighted posts, or customer/project information.
- Distinguish **newly published source material** from merely **newly discovered or indexed** old material. Record original source URL, stated publication/event date, observation date, confidence and source limitations.
- A group comment is not proof of a market trend, code requirement, or permit rule. Validate technical/legal claims against original official documents.
- Social-content drafts are proposals only. Use original wording and company-approved factual claims and images; no automatic publication.
